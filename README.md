# Payroll System (Java Interfaces & Comparable)

Advanced OOP exercise: polymorphism, interfaces, `Comparable`, and `Comparator`.

## Files
- `Taxable.java`, `BonusCalculable.java` - interfaces
- `Employee.java` - abstract class (implements the two interfaces + `Comparable<Employee>`)
- `FullTimeEmployee.java`, `ContractorEmployee.java` - concrete employees
- `PayrollSystem.java` - main program

## Run
```bash
javac *.java
java PayrollSystem
```

Requires JDK 11+.
